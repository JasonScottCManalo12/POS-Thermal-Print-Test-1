# POS Thermal Print Test 1

A small Flutter Android capstone test for a portable Bluetooth thermal printer.

## Initial target

- Printer: SENDA SDXP-210
- Model: PT210A
- First print target: `HELLO FROM FLUTTER!`

## Build

Every push to `main` starts the **Build Android APK** GitHub Actions workflow. When it succeeds, open the workflow run and download the artifact named `pos-thermal-print-test-1-debug-apk`.

## Current scope

This starter screen is only a build and UI milestone. Bluetooth discovery, connection, and printing are not implemented yet. No GCash, payment processing, or real transaction features are included.
